# ✳ LittleListing — AI Listing Studio

**Turn product details into marketplace-ready copy with open-weight AI.**

LittleListing is a lightweight web application for independent makers, freelancers, and small online sellers. It generates product titles, descriptions, and search tags using product information provided by the user.

Built with **HTML, CSS, and JavaScript**, LittleListing integrates with **Ollama** to run an open-weight AI model locally on your computer.

> **Project status:** Prototype / MVP. Test generated content and the local model connection before using the app in production.

## 💡 About the Project

Writing product listings can be time-consuming for small business owners. Every product needs an appealing title, a clear description, and relevant search tags.

LittleListing simplifies this process by transforming basic product details into ready-to-edit marketing copy.

The project explores how open-weight AI can help small businesses access useful AI features without depending entirely on paid, hosted AI APIs.

### 🎯 Target Users

- Etsy and eBay sellers
- Independent artists and makers
- Small ecommerce businesses
- Instagram shop owners
- Freelance product copywriters
- Handmade product businesses

## ✨ Features

- **AI Product Descriptions:** Generate descriptions based on product details.
- **SEO-Friendly Titles:** Create clear, searchable product titles.
- **Search Tags:** Suggest relevant tags for product discovery.
- **Multiple Platforms:** Choose Etsy, Instagram, eBay, Shopify, Amazon, or your own website.
- **Brand Voice Selection:** Choose Warm, Minimal, Playful, or Premium.
- **Local AI Integration:** Connect to an Ollama model running on your computer.
- **Model Flexibility:** Change the configured Ollama model.
- **Preview Mode:** Explore the interface without installing an AI model. This mode uses templates rather than AI.
- **Copy to Clipboard:** Copy titles, descriptions, tags, or the complete listing.
- **Recent Drafts:** Revisit recent results during the current browser session.
- **Responsive Design:** Use the application on desktop, tablet, and mobile screens.
