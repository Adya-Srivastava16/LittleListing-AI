littlelisting. A tiny tool for independent makers.

AI that works for the maker.

LittleListing uses an open-weight model through Ollama on your computer.

  1. Install Ollama from ollama.com.
  2. Run ollama run llama3.2 in your terminal.
  3. Serve this project locally and open it in your browser.
  4. Select Local Ollama and generate your listing.

Preview mode uses a template and does not require an AI model.
